# Spline 스타일 디자인

Spline.design은 "미니멀 + 3D + 화려함"이라는 서로 상충해 보이는 세 요소를 균형 있게 섞은 대표적인 레퍼런스입니다. 이 스킬은 그 균형을 재현하기 위한 가이드입니다.

## 핵심 원칙

Spline 스타일의 본질은 **여백은 넓게, 포인트는 강하게**입니다. 화면의 80%는 극도로 절제되어 있고, 나머지 20%가 시선을 강하게 붙잡는 시각 요소(3D 오브젝트, 큰 타이포, 그라디언트 블롭)로 채워집니다. 이 비율이 무너지면 "화려하지만 싸구려" 또는 "깔끔하지만 밋밋함" 둘 중 하나로 빠지기 쉬우니 항상 이 균형을 먼저 점검하세요.

## 1. 컬러 시스템

- **베이스**: 순백(#FFFFFF) 또는 아주 옅은 오프화이트(#FAFAFA~#F7F8FA) 배경을 기본으로 합니다. 다크 모드를 쓴다면 순검정이 아니라 딥 네이비/차콜(#0A0A0F~#12121A) 계열을 씁니다.
- **포인트 컬러 1개**: 브랜드 컬러를 하나만 강하게 씁니다. 이 컬러는 버튼, 강조 텍스트, 3D 오브젝트의 하이라이트에만 제한적으로 사용하고 배경 전체에 칠하지 않습니다.
- **그라디언트**: 단색 대신 2~3개 색의 부드러운 그라디언트(예: 보라→핑크, 블루→틸)를 배경의 블롭(blob)이나 3D 오브젝트 표면에 사용합니다. 그라디언트는 항상 큰 면적에 은은하게, 텍스트 위에는 쓰지 않습니다.
- **그레이스케일**: 텍스트와 구조 요소는 8~10단계의 그레이스케일로 위계를 만듭니다. 순검정 텍스트는 헤딩에만 쓰고, 본문은 70~80% 톤의 그레이로 눈의 피로를 줄입니다.

## 2. 3D / 시각 요소

이 스타일의 시그니처는 3D 오브젝트입니다. 실제 3D 렌더링이 불가능한 환경(정적 이미지, SVG, CSS)에서도 아래 방법으로 3D 느낌을 재현하세요.

- **글래스모피즘(Glassmorphism)**: `backdrop-filter: blur()`와 반투명 배경, 얇은 흰색 테두리(1px, opacity 10~20%)를 조합해 유리질감을 만듭니다.
- **소프트 섀도우 + 하이라이트**: 오브젝트 하단에 크고 부드러운 그림자(blur 40px 이상, opacity 낮게), 상단에 밝은 하이라이트를 넣어 입체감을 줍니다.
- **플로팅 블롭(Floating Blob)**: 배경에 흐릿한 원형/불규칙 그라디언트 도형을 2~3개 배치하고, 미묘한 애니메이션(위아래로 천천히 떠다니는 느낌, 8~12초 주기)을 줍니다.
- **이미지/일러스트 비중**: 텍스트만으로 섹션을 채우지 않습니다. 모든 주요 섹션에는 사진, 목업, 아이콘 일러스트, 3D 렌더 중 하나가 반드시 들어가야 합니다. 텍스트:이미지 비율을 대략 40:60 정도로 유지하세요.

## 3. 타이포그래피

- **디스플레이 폰트**: 헤딩은 크고(48px 이상), 굵고(Bold~Black), 자간을 살짝 좁힙니다(-1~-3%). 여기서 개성을 만듭니다.
- **본문 폰트**: 헤딩과 대비되도록 가벼운 weight(Regular~Medium)를 쓰고, 줄간격을 넉넉히(150~170%) 줘서 여백감을 유지합니다.
- **한 페이지에 폰트 패밀리는 최대 2개**까지만 씁니다. 폰트가 아니라 weight와 size로 위계를 만드세요.

## 4. 레이아웃 / 여백

- 섹션 간 여백을 아주 크게 잡습니다(최소 120px, 히어로는 160px 이상). Spline 특유의 "숨 쉬는 느낌"은 여백에서 나옵니다.
- 그리드는 비대칭을 두려워하지 마세요. 완벽한 좌우대칭보다, 텍스트는 좌측 40%에 배치하고 3D 오브젝트가 우측 60%를 침범하는 식의 비대칭 레이아웃이 더 역동적입니다.
- 카드나 버튼의 모서리는 완전한 각(0px)보다 부드러운 radius(12~24px)를 기본으로 씁니다. 다만 완전히 둥근(pill) 형태와 각진 형태를 섞어서 단조로움을 피하세요.

## 5. 모션

- 스크롤에 따라 3D 오브젝트나 블롭이 패럴랙스(parallax)로 움직이게 하면 고급스러움이 크게 올라갑니다.
- 호버 시 버튼이나 카드가 살짝 떠오르는(translateY -2~4px) 마이크로 인터랙션을 넣습니다.
- 모션은 항상 `ease-out` 계열의 부드러운 곡선을 쓰고, 과하게 튀는(bounce) 애니메이션은 피합니다. 절제된 모션이 프리미엄함의 핵심입니다.

## 6. 체크리스트 (빌드 전 자가 점검)

빌드하기 전에 아래 항목을 스스로 확인하세요.

- [ ] 배경은 여백이 지배적인가, 아니면 색으로 꽉 차 있는가? (전자여야 함)
- [ ] 3D/이미지 요소가 최소 히어로 섹션에는 반드시 들어갔는가?
- [ ] 포인트 컬러가 하나로 절제되어 있는가, 아니면 여러 색이 산발적으로 쓰였는가?
- [ ] 텍스트 위계가 2개 폰트, weight 차이만으로 충분히 표현되는가?
- [ ] 모든 모서리, 그림자, 애니메이션이 "부드러움"이라는 하나의 톤으로 통일되어 있는가?

## 참고 구현 스택

- React/HTML 아티팩트에서는 `frontend-design` 스킬의 톤 원칙(과도한 기본값 회피, 브리프에 맞춘 선택)과 함께 사용하세요.
- 실제 3D 인터랙션이 필요하면 `three.js`(r128, 이 환경의 제약 확인 필요) 또는 정적 3D 이미지를 에셋으로 활용하는 방식을 검토하세요.
- 글래스모피즘 CSS 예시:
```css
.glass-card {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.15);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.08);
  border-radius: 20px;
}
```

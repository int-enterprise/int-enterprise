# 스톡 사진 출처

사이트에 쓰는 스톡 사진의 출처와 라이선스 기록. **사진을 추가하면 여기에 반드시 적는다.**

## 규칙
- **상업적 사용이 명시적으로 허용된 소스만 쓴다.** 지금은 [Pexels](https://www.pexels.com/license/)를 쓴다.
  Pexels 라이선스: 무료 사용, 상업적 이용 가능, 출처 표기 의무 없음, 수정 가능.
- 구글 이미지 검색 결과나 출처가 불분명한 이미지를 가져다 쓰지 않는다.
- **사진은 그 자리의 내용과 맞아야 한다.** 아무 사무실 사진이나 채우지 않는다
  (기록 이야기에는 기록하는 장면, 데이터 이야기에는 지표를 보는 장면).
- **회사 자산 사진**을 쓸 때는 화면·현수막·명패에 고객사명이 찍혀 있지 않은지 먼저 확인한다.
- 이미지를 같은 파일명으로 교체하면 next/image 캐시가 예전 것을 계속 내보낸다.
  `.next/cache/images`를 비우거나 파일명을 바꾼다.
